Cómo funciona. Todo se guarda solo en este navegador mientras editas. Cuando termines, pulsa Descargar cambios: se bajan los archivos .json modificados.
  1. Sube esos archivos a GitHub dentro de docs/data/ (reemplazando los que están).
  2. Si agregaste fotos nuevas, súbelas también a docs/assets/img/ con el mismo nombre que pusiste aquí.
  3. En 1–2 minutos el sitio se actualiza solo.

Importante: el cambio no se ve en el sitio hasta que subas el .json descargado a GitHub. El panel solo prepara el archivo.
